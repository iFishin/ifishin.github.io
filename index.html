缸中五族，形色各异。

猫说

缸边这只黑猫，其实一直在看。

  • 盯着鱼看——视线跟着最靠右的那条鱼移动。
  • 点它——会应你一声，声音是 Web Audio 现合成的，没有音频文件。
  • 鱼游到右边——它会好奇前倾，偶尔伸爪拍一下。
  • 许久没人理——打哈欠、理毛，最后打起瞌睡；碰一下鱼缸就醒。
  • 惊扰鱼群——它会被吓一跳，尾巴立刻竖起来。

耳朵会抖、胡须会颤、尾巴一圈圈地摆——这些不是随机噪声，是按各自节奏叠加出来的。

关于

一个水墨风格的在线鱼缸。

纯静态页面，没有构建步骤，也没有框架依赖——打开 index.html 就跑。鱼、猫、柳树全是 SVG 画的，声音是 Web Audio 实时合成的。

鱼是有性格的

每条鱼都有自己的好奇心、顽皮度、食欲、竞争性与社交性。这些数值驱使它游向食物、追逐同伴、圈占领地，或者凑过来看你的光标。它们会长大，也会变老。

可以怎么玩

  • 投喂：点鱼缸里任意位置撒食，或按 F。
  • 看鱼：点中某条鱼，会告诉你它的种类、岁数和已经吃了几口。
  • 惊扰：按 S 或点「惊扰」，鱼群四散，而且恐惧会传染给旁边的鱼。
  • 逗猫：点一下猫它会叫；在它身上按住来回摩挲，它会眯起眼睛打呼噜。
  • 看鱼跃：双击鱼缸，会有鱼跃出水面。
  • 拖着玩：右键按住可以拖动一条鱼，手机上直接用手指拖。
  • 暂停：按 空格 定格整个画面。
